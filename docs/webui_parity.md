## 与 Qt 端的有意差异

- WebUI 的评分覆盖、收藏存在浏览器 `localStorage`，不写 `app/data/tierlists/*.local.json`；导出 JSON 后可与桌面端互换。
- WebUI 不包含「装备对应规则编辑器」；需要改规则时用桌面端或直接改 `app/data/equipment_targets.json` 后 `build_web.py`。
- WebUI 不内嵌 Qt 的整篇帮助文档，入口在 README / `web/README.md` / `docs/`。
- WebUI 首次打开在 PC 同源环境会**自动尝试 `/api/latest`**；Android APK 没有该接口，用「导入 / 连接」。
- 组件依赖 `index_*.json`：`/api/latest` 会自动合并；单独导入 `account_*.json` 时组件页会提示缺失。桌面端「导出账号」已改为自动带组件。
